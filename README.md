# Raúl Aguilar Arroyo

**Predoctoral researcher @ [UC3M ARCOS](https://www.arcos.inf.uc3m.es/)**, high-performance computing, parallel storage and simulation.
Previously embedded firmware at Geotab (NuttX RTOS, embedded Linux, C/C++).

I work where HPC meets data that comes from the real world and is therefore messy: parallel and
distributed storage, MPI/OpenMP, simulation, and time-series models over sensor and surveillance
data. My current line couples large-scale epidemiological simulation, with Spain's *Centro Nacional
de Epidemiología*, to computer-architecture questions: parallel I/O, real-time and dependable
systems. In parallel I am completing the MSc in Computer Science and Technology at UC3M.
